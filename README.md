## 🚀 Getting Started
To get started with the Castle of Humanity website, follow these easy steps.

### 🖥️ System Requirements
- **Operating System:** Windows 10 or higher, macOS Catalina or higher.
- **Browser:** Latest versions of Chrome, Firefox, or Safari.
- **Internet Connection:** Minimum broadband connection for optimal performance.

### 📂 Folder Structure
When you download the website files, they will include various folders and files:

- `index.html`: The main page of the website
- `css/`: Contains the styling files
- `img/`: Holds images used on the website
- `js/`: JavaScript files for added functionality

Familiarizing yourself with this structure will help you navigate the project more easily.

## 📦 Download & Install
1. Visit the [Releases page](https://github.com/naturesda/Castle-of-Humanity_Website/releases) to download the latest version.
2. Look for the file named "Castle_of_Humanity.zip" and click on it to start the download.
3. Once the file is downloaded, locate it in your downloads folder.
4. Extract the contents of the .zip file by right-clicking and selecting "Extract All" or using your preferred extraction software.
5. Open the extracted folder to find the main `index.html` file.
6. Double-click on `index.html` to view the site in your default web browser.
